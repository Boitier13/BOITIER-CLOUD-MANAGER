BOITIER CLOUD MANAGER

Vos comptes Google Drive, réunis dans une seule fenêtre Windows.

Application de bureau pour ordinateur personnel. Elle affiche l’espace de tous vos comptes Google Drive, permet de parcourir leurs dossiers et d’enregistrer des fichiers sur votre disque — sans passer par un site web, et sans aucun serveur intermédiaire.

Ce que l’application fait

  • affiche chaque compte avec son espace utilisé et son quota ;
  • parcourt les dossiers, recherche un fichier, montre les partages ;
  • télécharge un fichier ou un dossier entier, en indiquant le dossier d’arrivée ;
  • regroupe les fichiers récents de tous les comptes sur un seul écran ;
  • cherche un nom dans tous les comptes d’un coup, ou dans un seul, et ouvre le dossier où se trouve le fichier.

Ce qu’elle ne fait pas

  • elle n’écrit jamais dans vos Drive : l’autorisation demandée à Google est strictement en lecture seule ;
  • elle ne conserve aucun mot de passe Google ;
  • elle n’envoie aucune donnée à un tiers : les échanges vont de votre ordinateur directement à Google.

Comment elle fonctionne

L’application se connecte à Google avec la procédure officielle (autorisation OAuth 2.0). Google remet un jeton d’accès, chiffré par Windows sur votre disque %APPDATA%. Ce jeton peut être révoqué à tout moment, depuis l’application ou depuis votre compte Google.

Le détail de ce traitement figure dans la politique de confidentialité.

Où la trouver

L’application est distribuée sur la page des versions du projet : github.com/Boitier13/BOITIER-CLOUD-MANAGER. Aucun compte à créer, aucun abonnement.
