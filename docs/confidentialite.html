BOITIER CLOUD MANAGER

Politique de confidentialité

BOITIER CLOUD MANAGER est une application de bureau pour Windows. Elle n’a pas de serveur applicatif : votre ordinateur communique avec les fournisseurs que vous choisissez et avec GitHub pour les mises à jour.

1. Données consultées

Après votre autorisation, l’application lit auprès de Google les informations suivantes, et seulement celles-là :

Identité du compte
Nom affiché, adresse électronique, photo de profil si elle existe.
Espace de stockage
Volume utilisé, quota total, répartition par type de fichier.
Fichiers et dossiers
Nom, type, taille, date de modification, identifiant — pour afficher l’arborescence de votre Drive.

Le contenu est téléchargé lorsque vous demandez une copie ou un export de document Google. L’accès Google reste en lecture seule : l’application ne peut pas modifier, renommer ou supprimer vos fichiers Google.

L’application peut aussi se connecter à MEGA, Shadow Drive et TeraBox pour afficher les comptes, les dossiers et télécharger des fichiers. MEGA permet également l’envoi de fichiers à votre demande. TeraBox utilise un accès Web non officiel et provisoire, susceptible de changer.

2. Autorisation demandée

Pour Google Drive : https://www.googleapis.com/auth/drive.readonly. Elle autorise la consultation des fichiers et l’enregistrement d’une copie sur votre disque. Toute écriture chez Google est refusée par Google lui-même, pas seulement par l’application.

3. Ce qui est conservé sur votre ordinateur

  • Les jetons d’accès, dans %APPDATA%\BOITIER CLOUD MANAGER\google-accounts.enc, chiffrés par Windows (Data Protection API). Sans votre session Windows, ce fichier est illisible.
  • Les sessions MEGA et TeraBox et le jeton Shadow Drive sont conservés dans des coffres distincts, chiffrés par Windows. Ces secrets donnent accès aux comptes et ne doivent pas être partagés.
  • Vos préférences et la liste de vos comptes, dans le stockage local de l’application.
  • Un journal de démarrage (version lancée, résultat du chargement, incidents et transferts). Il peut contenir des noms de fichiers, chemins locaux, adresses ou identifiants ; vérifiez-le avant de le partager et ne partagez jamais vos jetons, cookies ou mots de passe.

4. Ce qui n’est jamais fait

  • aucune donnée envoyée à un serveur applicatif du projet ;
  • aucune mesure d’audience, aucun traçage, aucune publicité ;
  • aucun mot de passe Google demandé ni conservé ;
  • pas de revente de vos données par le projet. Les fournisseurs et GitHub reçoivent les requêtes nécessaires aux fonctions utilisées.

5. Vos droits, en pratique

Retirer un compte
Dans l’application, la déconnexion efface l’entrée chiffrée du fournisseur concerné. Pour Google, elle demande aussi la révocation du jeton. Une session peut rester active chez les autres fournisseurs ; vérifiez leurs réglages de sécurité si vous souhaitez la révoquer.
Tout effacer
Supprimer le dossier %APPDATA%\BOITIER CLOUD MANAGER efface comptes, jetons et préférences. Les fichiers déjà téléchargés restent où vous les avez enregistrés.
Révoquer depuis Google
Page Sécurité de votre compte Google, rubrique « Applications tierces ayant accès au compte ».

6. Durée de conservation

Les données locales restent sur votre ordinateur jusqu’à leur suppression ; une désinstallation ne les efface pas nécessairement. Les fournisseurs conservent les données de vos comptes selon leurs propres politiques.
